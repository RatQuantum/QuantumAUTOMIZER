# Strategy 10: lock-in, two re-hooks, loop ending

Built on checkpoint-1 (see CHECKPOINTS.md) after the Day 41-50 insights, plus two reference reels the owner sent (not stored).

## What the data said (Day 45, typical of 41-50)

- ~1.35k-1.6k views every reel: Instagram's test batch, no breakout.
- Retention: about half leave in the first 4-5 s; after that the curve is flat (~40% → 30%); a drop at the end card.
- Average watch ≈ 13-14 s of 33 s. 99.9% non-followers. 0-6 shares a reel.

So the middle works (keep it). The first 5 seconds, the end and the share/follow asks don't.

## Reference A: the watch-time ladder

| Level | Avg watch | Fix |
|---|---|---|
| 100 views | 1.8 s | hook: broad, curiosity gap, proof |
| 1k | 6.2 s | re-hook the body with "but", open new loops, show value a new way |
| 10k | 13.5 s | get to the point fast, but don't pay off too early (keep edging) |
| 100k | 24 s | repeat what worked |

## Reference B: the script format

Hook → **lock-in zone** → body 1 → **re-hook 1** → body 2 → **re-hook 2** → (body 3) → (closing) → **CTA with an aligned gift**.

## The new reel template (Days 51+)

| Beat | Time | Rule |
|---|---|---|
| Hook | 0-2 s | First frame is mid-action (never a calm pose). Stakes + gap in one line, spoken from 0.06 s. Title card = the same idea in 3-4 words. |
| Lock-in | 2-5 s | One spoken line that promises the payoff: "Stay till the end, because…". This targets the 4-5 s cliff. |
| Body 1 | | The setup, new shot every 2-3 s. |
| Re-hook 1 | ~35% | Starts with "But…", opens a new loop. |
| Body 2 | | Escalate. |
| Re-hook 2 | ~55% | The existing "Wait, …?" beat + pinned comment banner. |
| Payoff | 70-80% | Held back until here. |
| Closing | | "That's why we…" one line; the last spoken phrase leads back into the hook (loop). |
| CTA | last 3 s | Comment word **and** a share line: "send this to someone who…". On screen: "DAY N · FOLLOW FOR TOMORROW'S STORY". |

Also: a cover image per reel (the hook frame + 3-4 words), since thumbnails of calm, standing Krishna don't stop the scroll.

## Measure (72 h after posting 51-55)

3-second hold, hold at 5 s, average watch time, shares, follows per reel. If it's worse than checkpoint-1, roll back.
